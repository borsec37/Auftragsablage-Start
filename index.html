Es tut sich nichts?

  1. Nachfrage des Browsers bestätigen. Beim ersten Mal erscheint ein kleines Fenster mit der Frage „Auftragsablage öffnen?“. Erst wenn Sie das bestätigen, startet die Anwendung.
  2. Auftragsablage einmal von Hand starten. Auf einem Rechner, auf dem die Anwendung noch nie gelaufen ist, kennt Windows diesen Link noch nicht. Führen Sie dazu Auftragsablage.cmd einmal per Doppelklick aus – Sie finden die Datei in SharePoint neben diesem Link. Danach funktioniert der Link dauerhaft.
  3. Diese Seite neu laden. Nach dem ersten Start genügt ein Klick auf den Knopf oben.

Der Link öffnet die Anwendung auf Ihrem eigenen Rechner – er lädt nichts aus dem Internet. Deshalb muss die Auftragsablage dort einmal eingerichtet worden sein.
